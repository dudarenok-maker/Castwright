# 煤落的委托 — The Coalfall Commission (bundled sample, Chinese)

An original Castwright work, all rights reserved. The Chinese (`zh`) edition of the fs-22 generate-able demo book, bundled for the fs-59 CJK rollout. No audio ships — the demo runs the real pipeline locally (the analysis cache rebuilds from the manuscript on the first generate).

**Minimal sample:** the cast roster is real (analysed from the manuscript) but carries **no designed voices** yet — `overrideTtsVoices` is empty for every character. Designed per-character Qwen voices are backfilled later via the app, tracked in issue #1600. Until then, generating this book falls back to a generic voice per character.
