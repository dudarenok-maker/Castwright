# fs-38 Wave 3c — XTTS voice clone Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a cloned voice render on the Coqui XTTS v2 engine as well as Qwen — deriving XTTS conditioning latents from the same retained `master.wav`, and carrying the never-silent-substitution invariant through every coqui seam that currently falls back to a stock speaker.

**Architecture:** The clone identity already lives in the voice-library entry (`master.wav` + consent). 3c adds a **second derivable artifact** for that identity: `voices/xtts/xtts-<uuid>.pt` (gpt conditioning latents + speaker embedding), produced by a new sidecar route `POST /xtts/clone-voice` from the same PCM the Qwen route consumes. Everything downstream becomes **engine-parametric** rather than Qwen-hardcoded: the resolver classifies per engine, `pickVoiceForEngine` gains a coqui `libraryUuid` branch returning `xtts-<uuid>`, and `CoquiEngine.synthesize` learns to recognise that id space **before** its `FALLBACK_SPEAKER` substitution check. Derivation is **lazy** — assignment writes both clone-capable engine slots, and whichever engine a chapter actually routes to gets its artifact derived by the existing 3b2 pre-pass.

**Tech Stack:** Python 3.12 sidecar (FastAPI, coqui-tts 0.27.5, torch), Node 20 + TypeScript server (Express, Vitest), React 18 + RTK frontend, Playwright e2e, pytest.

## Global Constraints

Every task's requirements implicitly include this section.

- **`TtsEngine` has no `'xtts'` value.** The engine is `'coqui'` (`server/src/tts/model-keys.ts:18`). `xtts` is **only** (a) the voice-library manifest slot key `engines.xtts`, (b) the artifact dir `voices/xtts/`, and (c) the storage-key prefix `xtts-<uuid>`. Never add `'xtts'` to `TtsEngine`, and never route on `engine === 'xtts'`.
- **The headline invariant, unchanged from 3b1/3b2:** a cloned-provenance voice either renders as itself or fails loud. It is never substituted — not by `FALLBACK_SPEAKER`, not by `applyQwenFallback`, not by the coqui profile catalog.
- **OpenAPI is the type source of truth.** `VoiceLibraryEngines.xtts` already exists (`openapi.yaml:5089-5095`) with `coquiVersion` + `modelId` (NOT `baseModel`). If any wire shape changes, edit `openapi.yaml` then run `npm run openapi:types`. **Never hand-edit `src/lib/api-types.ts`.**

- **User-facing copy names the engine "Coqui XTTS v2"** (matching `src/components/coqui-install.tsx`), never bare "XTTS". The short label in the mixed-engine caption stays `"Coqui"` (`src/lib/tts-models.ts:146-152`).

## Design decisions — four deviate from the approved spec and need sign-off

| # | Decision | Spec said | Why the change |
|---|---|---|---|
| **D-A** | **No engine picker in the clone wizard.** Clone always derives Qwen first (unchanged `/clone` route); the XTTS artifact is derived lazily by the pre-pass when a chapter routes the character to coqui. | §6: "Phase 2 (3b1, **+engine choice 3c**)". | `master.wav` retention plus `deriveEngineArtifact(uuid, engine)` — which §4.2 itself says "serves engine-switch + orphan self-heal" — already makes derivation on-demand. An up-front picker asks the user to commit to an engine they cannot yet evaluate, adds a wire field, and creates a wrong-choice repair path. Lazy derive is strictly less code and strictly more forgiving. |
| **D-B** | **Designed-voice XTTS eligibility is deferred out of 3c** (files a follow-up). 3c covers **cloned** voices on XTTS only. | Wave table: "designed-voice XTTS-eligibility (**spike-gated**)"; §2.3 caveat: deriving XTTS latents from a *synthetic* Qwen calibration clip is "quality-unvalidated". | It is the one part of 3c whose output quality is genuinely unknown, and it is separable. Shipping cloned-on-XTTS (real human reference clip, the case the feature exists for) does not depend on it. Folding it in couples a known-good deliverable to an open quality question. |
| **D-C** | **Hand-rolled latents**: `get_conditioning_latents()` + `_atomic_torch_save`, not coqui's built-in `CloningMixin.clone_voice(..., voice_dir=)`. | Not addressed. | The built-in caches to `<voice_dir>/<slugify(speaker_id)>.pth` — a slugified name we do not control, so `purgeCloneArtifacts` could not reliably erase a revoked person's artifact, and the write is a plain `torch.save` (not atomic). Path control and atomicity are consent-critical here. |
| **D-D** | **A sidecar voice substitution of a cloned key is FATAL on the Node side**, not a warning. | Not addressed. | `sidecar.ts:188-195` currently only `console.warn`s on `X-Voice-Substituted-From`, so a render "succeeds" with the wrong voice. Task 3 closes this in the sidecar; this is the belt-and-braces that survives a future sidecar regression. |
| **D-E** | **Assign writes BOTH clone-capable slots** (`overrideTtsVoices.qwen` *and* `.coqui`) with the same `libraryUuid` + `provenance:'cloned'`. | Not addressed (§6 says "`overrideTtsVoices` with `libraryUuid` + `provenance:'cloned'`", singular). | Closes a silent-substitution hole: with only the qwen slot written, switching the book to coqui leaves the coqui slot empty, `pickVoiceForEngine` falls through to `COQUI_PROFILE_VOICES`, and a real person is replaced by a stock speaker with no error. Writing both slots means the clone is found on whichever engine renders. |

**Settled without deviation** (from the spec, restated so tasks can cite them): artifact path `voices/xtts/xtts-<uuid>.pt` (§2.2); wire key `xtts-<uuid>` via a coqui `libraryUuid` branch in `pickVoiceForEngine` (§3.2/I3); the latents branch must fail loud rather than reach `FALLBACK_SPEAKER` (§5.3); revoke/delete erase the xtts artifact too (§5.6).

```python
    def _voice_paths(self, voice_id: str) -> tuple[str, str]:
        """Filename-safe (.pt, .json) pair for a cloned XTTS voice id.

        Identical sanitisation to QwenEngine._voice_paths: identity for an
        already-ASCII id, and a short stable hash appended when sanitisation
        is lossy so the mapping stays injective.
        """
        safe = re.sub(r"[^A-Za-z0-9_.-]", "_", voice_id)
        if safe != voice_id:
            digest = hashlib.sha1(voice_id.encode("utf-8")).hexdigest()[:8]
            safe = f"{safe}-{digest}"
        return (
            os.path.join(self._voices_dir, f"{safe}.pt"),
            os.path.join(self._voices_dir, f"{safe}.json"),
        )
```

```python
    # fs-38 Wave 3c — the coqui-tts release this artifact was derived with.
    # Persisted alongside the latents and echoed to Node so a package bump
    # can mark the artifact stale (the engines.xtts.coquiVersion field).
    def _coqui_version(self) -> str:
        try:
            from importlib.metadata import version  # type: ignore
            return str(version("coqui-tts"))
        except Exception:
            return "unknown"

    def clone_voice(
        self,
        voice_id: str,
        ref_audio: Any,
        ref_sr: int,
        audition_text: Optional[str],
        language: Optional[str] = None,
        model: str = "xtts_v2",
        device: Optional[str] = None,
    ) -> SynthResult:
        """Derive XTTS conditioning latents from a reference clip and persist
        them under voices/xtts/<voice_id>.pt, returning an audition preview.

        Fails loud — never falls back to a baked speaker. Mirrors
        QwenEngine.clone_voice's contract so deriveEngineArtifact can treat
        both engines identically.
        """
        import torch  # type: ignore

        self._ensure_loaded(model, device=device)
        assert self._tts is not None
        tts_model = self._tts.synthesizer.tts_model
        lang = (language or self._language or "en").strip() or "en"
        audition = (audition_text or "").strip() or "This is how my voice sounds."

        os.makedirs(self._voices_dir, exist_ok=True)
        pt_path, json_path = self._voice_paths(voice_id)

        # get_conditioning_latents takes a PATH (xtts.py:331), not an array —
        # write the already-normalised PCM to a temp WAV beside the artifact.
        fd, tmp_wav = tempfile.mkstemp(dir=self._voices_dir, suffix=".ref.wav")
        os.close(fd)
        try:
            _atomic_wav_save(_float_audio_to_int16_le(ref_audio), int(ref_sr), tmp_wav)
            gpt_cond_latent, speaker_embedding = tts_model.get_conditioning_latents(
                audio_path=tmp_wav
            )
        finally:
            try:
                os.remove(tmp_wav)
            except OSError:
                pass

        _atomic_torch_save(
            torch,
            {"gpt_cond_latent": gpt_cond_latent, "speaker_embedding": speaker_embedding},
            pt_path,
        )
        import json as _json
        with open(json_path, "w", encoding="utf-8") as fh:
            _json.dump(
                {
                    "voiceId": voice_id,
                    "language": lang,
                    "coquiVersion": self._coqui_version(),
                    "modelId": model,
                    "clone": True,
                },
                fh,
                ensure_ascii=False,
                indent=2,
            )

        out = tts_model.inference(
            text=audition,
            language=lang,
            gpt_cond_latent=gpt_cond_latent,
            speaker_embedding=speaker_embedding,
        )
        sample_rate = int(getattr(self._tts.synthesizer, "output_sample_rate", 24000))
        log.info("Cloned + cached XTTS voice '%s' from caller clip.", voice_id)
        return SynthResult(pcm=_float_audio_to_int16_le(out["wav"]), sample_rate=sample_rate)
```

Add the loader (mirrors `QwenEngine._load_voice_prompt`, `main.py:4172-4208`):

```python
    def _load_voice_latents(self, voice: str) -> tuple[Any, Any]:
        """Load cached XTTS conditioning latents for a cloned voice id.

        Fails loud when the artifact is absent — a cloned voice must never
        degrade into a baked speaker (fs-38 spec §5.3). /synthesize maps
        VoiceNotDesignedError to a 409.
        """
        with self._latents_lock:
            cached = self._latents_cache.get(voice)
        if cached is not None:
            return cached
        pt_path, _json_path = self._voice_paths(voice)
        if not os.path.isfile(pt_path):
            raise VoiceNotDesignedError(
                f"Cloned XTTS voice '{voice}' has no conditioning latents on disk. "
                "Re-derive it from the retained sample before rendering."
            )
        assert self._torch is not None
        blob = self._torch.load(pt_path, weights_only=False)
        pair = (blob["gpt_cond_latent"], blob["speaker_embedding"])
        with self._latents_lock:
            self._latents_cache[voice] = pair
        return pair
```

```python
@app.post("/xtts/clone-voice")
async def xtts_clone_voice(req: Request) -> Response:
    """Derive XTTS conditioning latents from a caller-supplied reference clip
    (raw s16le mono PCM body) and return an audition preview (PCM, same wire
    shape as /synthesize). Headers: X-Sample-Rate (required), X-Voice-Id
    (required, the xtts-<uuid> id), X-Audition-Text (base64, optional),
    X-Language (optional). No X-Ref-Text — get_conditioning_latents is a
    purely acoustic derivation and takes no transcript. Fails loud (never
    FALLBACK_SPEAKER) on derive/audition error."""
    if _process_poisoned:
        return JSONResponse(
            {"detail": "Voice engine is in a poisoned CUDA state; restart required.",
             "poisoned": True}, status_code=503)
    if _restart_pending:
        return JSONResponse(
            {"detail": "Voice engine is recycling to free memory; retry shortly."},
            status_code=503)

    pcm = await req.body()
    if not pcm:
        raise HTTPException(status_code=400, detail="empty PCM body")
    try:
        sample_rate = int(req.headers.get("X-Sample-Rate", "0"))
    except ValueError:
        sample_rate = 0
    if sample_rate <= 0:
        raise HTTPException(status_code=400, detail="X-Sample-Rate header (>0) is required.")
    voice_id = (req.headers.get("X-Voice-Id") or "").strip()
    if not voice_id:
        raise HTTPException(status_code=400, detail="X-Voice-Id header is required.")

    audition_text: Optional[str] = None
    raw_audition = req.headers.get("X-Audition-Text")
    if raw_audition:
        try:
            audition_text = _b64.b64decode(raw_audition).decode("utf-8")
        except Exception:
            audition_text = None
    language = (req.headers.get("X-Language") or "").strip() or None

    coqui = ENGINES.get("coqui")
    if not isinstance(coqui, CoquiEngine):
        return JSONResponse({"detail": "coqui engine missing"}, status_code=500)
    ref_audio = np.frombuffer(pcm, dtype="<i2").astype(np.float32) / 32768.0

    global _inflight_synth
    _inflight_synth += 1
    try:
        if _capacity_admission_enabled():
            cap = _ENGINE_CAPACITY_PROFILE.get("coqui", {"cpu_capable": False, "heavy": True})
            with _placement.reservation(
                "coqui", None, {"op": "clone"},
                cpu_capable=cap["cpu_capable"], heavy=cap["heavy"],
                pinned=_engine_env_pin("coqui"),
            ) as adm:
                if "noCapacity" in adm:
                    return _no_capacity(adm)
                result = await asyncio.to_thread(
                    coqui.clone_voice, voice_id, ref_audio, sample_rate,
                    audition_text, language, "xtts_v2", adm["device"],
                )
        else:
            result = await asyncio.to_thread(
                coqui.clone_voice, voice_id, ref_audio, sample_rate,
                audition_text, language,
            )
    except Exception as e:
        if _CUDA_POISON_RE.search(str(e)):
            _mark_poisoned(str(e))
            return JSONResponse(
                {"detail": str(e), "poisoned": True, "code": "gpu_poisoned"}, status_code=503)
        log.exception("/xtts/clone-voice failed")
        return JSONResponse({"detail": "Internal error."}, status_code=500)
    finally:
        _inflight_synth -= 1

    return Response(
        content=result.pcm,
        media_type=f"audio/L16;codec=pcm;rate={result.sample_rate}",
        headers={
            "X-Sample-Rate": str(result.sample_rate),
            "X-Coqui-Version": coqui._coqui_version(),
            "X-Model-Id": "xtts_v2",
        },
    )
```
