**The voice-cloning release.** Castwright can now clone a voice from a short consented sample and cast it like any other, on **both** speech engines and in the book's own language, with a never-substitute promise that fails loud rather than quietly handing a character to a stand-in. Around it: a character's identity survives a re-analysis, GPU memory reclaims itself before anything is refused for lack of room, the sidecar stops stalling other requests while it frees a model, engine-health reporting tells a missing package from a broken one, and Listen-view loudness numbers are measured.

> ⚠️ **Upgrade note:**
>
> - **Node 22.22 is the new floor** (was 20.19). `engines` is advisory, so check `node --version` before upgrading a self-managed install. Pinokio installs provision their own Node 24 but converge one Update late (#1859, #1878).
> - **ffmpeg 6.0 is the new minimum** and **Ubuntu 22.04 is retired** (its ffmpeg is 4.4). Surfaces warn; only the preflight hard-fails. Snap or a PPA satisfies the floor on 22.04 (#1877).
> - **An existing Coqui install must be Repaired** to pick up the long-line clone fix: press **Repair Coqui XTTS v2** in Admin → Model Manager → Installed models (#2017).
> - **Existing `onnxruntime-gpu` 1.27.x and 1.28.x installs step back to 1.26.x** on first upgrade, through both the Pinokio and in-app upgrade paths (#2534, #2576).
> - **The next Pinokio Update or in-app zip upgrade runs a one-time full voice-engine reinstall**, and takes longer than usual; on NVIDIA it also downloads about 1.3 GB more (the cuDNN and cuBLAS wheels). A plain restart does not trigger it (#2586, PR #2588, #2600).
> - **A zip install with `mkcert` on PATH now serves LAN HTTPS by default**: it binds `0.0.0.0` with HTTPS on `:8443`, behind an auto-minted `LAN_AUTH_TOKEN`, instead of loopback HTTP on `:8080`. Set `LAN_HTTPS=0` to opt out; without `mkcert` it still falls back to loopback HTTP with a warning. The v1.14.0 zip left out the LAN cert setup, Windows sleep prevention (`prevent-sleep`) and the scripts behind `npm run tts:sidecar` and `npm run install:cert-mobile`; all now ship (PR #3404).
> - **Books already rendered against a drifted character id are not repaired in place.** An affected chapter needs a re-render; `scripts/repair-cast-id-drift.mjs` is the offline pass for the rest (#2040).

## ✨ Headline features

### 🎤 Clone a voice — and cast it on either engine (new) — fs-38

Record or upload a short sample, attest consent, and Castwright distils a reusable cloned voice you can give to any character in any book, on Qwen or Coqui XTTS v2. A cloned voice is never silently substituted: if it cannot render, the chapter fails loud.

- **A book-independent voice library** (#1800, refs #624). `#/voices` now has three sections, **My voices | In use | Catalogue**. Create a Qwen voice from a persona with a live audition, redesign with an A/B compare, promote a character's designed voice into the library, and assign a library voice to any character across books and series. Voices carry a provenance (`designed`/`cloned`/`imported`); the cross-book voice matcher never offers a cloned voice into another book. Deleting a library voice reports usage and erases every copy.
- **Ingest, consent and recorder** (refs #624). Upload or record a sample (quality-checked, capped at 60s, transcribed by Whisper) and attest consent in the capture panel. My voices shows a 'Cloned' badge and a **Revoke** action; a revoked or consent-less clone cannot be auditioned. Revoke erases the original recording and all derived artifacts behind a two-step confirm, so "revoke" means the recording is gone.
- **The never-substitute guarantee** (refs #624). Before any synthesis, a per-chapter check transparently re-derives a repairable cloned voice and hard-fails the chapter on a broken one (revoked, missing recording, engine unavailable, wrong engine, or a persisted derive failure). A transient sidecar hiccup never permanently bricks a voice. A cloned voice assigned to a character that does not route to a clone-capable engine is refused with a clear message. Generation shows a "Preparing voice - character" phase during a re-derive (#1813).
- **Coqui XTTS v2 clones** (refs #624). Clones and designed voices now work on Coqui too, with the same total erasure on revoke and delete; if any artifact cannot be erased the library entry is kept and flagged rather than deleted, so consent checks still apply (#1804, #1885, #1887, #1891, #1899). Assigning a clone fills both engine slots when it can render on both, and a new **Remove voice** control takes a library voice back off a character. Redesign and promote are refused on a cloned voice, and bulk "Design full cast" skips cloned characters and names them. XTTS is freed at the end of a chapter's Coqui phase instead of staying resident (#1932, #1890, #1896, #1892).
- **Clone in the book's language** (#1951, #1998). Cloned voices now render in the book's language rather than English, and the speaker-drift reference follows it. The wizard tells you to record in the language you want read: a Russian-sourced clone scored 0.78 identity against its own source versus 0.23 for an English-sourced clone (the Russian source was itself a Qwen-designed voice, so the margin is narrower than the raw number). Assigning a clone whose source language differs from the book's returns a non-fatal warning. Existing clone manifests keep reading "English" until re-cloned.
- **Consent records name the real attester** (#1943, #1959). The consent record can name who attested; for a guardian-of-minor or family relationship the attester is required, and the record can no longer claim a minor attested for themselves.
- **Wizard and cast-time safeguards** (#1840, #1933, #1980, #2054, #2068, #2650). Edits to the clone wizard's transcript now reach the voice (max 2000 chars). Assign checks the engine a clone will actually render on, and approving the cast warns before a render that cannot work, with fixes: add a transcript, retry the derive, cast on another engine, or assign a different voice. **Proceed anyway** still starts the render. A transcript edit whose sample has vanished says why and what to do; cloning refreshes your library rather than showing a stale status.
- **Emotion variants are refused for a cloned voice** (#1954), since a variant is a re-performance of a real person that consent and erasure could not cover.
- **Cloning works on a static-FFmpeg install** (refs #1967). Coqui clone derive no longer needs FFmpeg's shared libraries (the normal `winget install Gyan.FFmpeg` build), the installer now verifies this, and failure messages no longer wrongly say to re-enable Qwen on a Coqui failure (#1979).
- **Long lines and Japanese on cloned Coqui voices** (#2017, #2038). A long line no longer 500s; Japanese text-splitting now works, adding about 69 MB (SudachiPy) to a Coqui install. Both land only on a fresh Coqui install or **Repair**/reinstall.

On-hardware acceptance (a real sidecar and a real cloned voice) is still owed for Wave 3 and the cast-time gate.

### 🪪 A character's identity now survives a re-analysis — #2040

A character's `id` is free text the analyzer mints, and it ties together the cast, the analysis cache and every narrated chapter. When a re-analysis minted a different id for the same person, an already-narrated chapter could no longer tell whose line it was and quietly fell through to the narrator. A scan of a real 20-book workspace found drift in 18 books and 188 orphaned segments. Three staged waves resolve it, stop creating it, then surface and repair what is left.

- **Drifted ids now resolve at render time, and a re-analysis stops minting them.** Ids that differ only by case or separator (`the_torment` / `the-torment`) resolve to the same character, a per-book history records every retired id, and a re-analysis adopts the cast's existing id for a character it matches by name instead of minting a new one. Creating a character can no longer re-mint an id a merge already retired (#2040, #2082, #2087, #2085, #2110, #2584, PR #2640). **Audio already on disk is not repaired in place**: a chapter rendered with the narrator substituted keeps that audio until it is re-rendered.
- **An orphaned id is no longer a silent narrator fallback.** The render records the substitution; the Cast view shows an advisory banner naming the orphaned id(s), and a line that would borrow a **cloned** narrator voice now fails with `cloned-voice-broken` instead of substituting (#2023).
- **The Cast banner splits "auto-reconciled" from "needs your decision."** Auto-reconciled rows say whether their audio is current or needs a re-render. Needs-decision rows have a **Link to this character** button, and both sections have an undoable, pair-scoped **Not the same character** button (with an "X is not Y" chip). Reserved background buckets (`unknown-male` / `unknown-female`) cannot be linked (#2092, #2089, #2129, #2128, #2238, #2161, #2133, #2166, #2244).
- **Operator repair scripts.** `scripts/repair-cast-id-drift.mjs` lists the chapters to re-render and records unambiguous aliases (dry run by default; `--apply` refuses if a server may be live, on an unreadable book, or on a zero-book scan); `scripts/repair-a34-wrong-direction-ids.mjs` reinstates ids a pre-#2640 run retired in the wrong direction. Both take a backup before writing (#2097, #2107, #2108, #2130, #2134, #2135, #2093, #2090, #2111, #2903, #3057, #3095). On-hardware acceptance of the repair runs is recorded in the acceptance register.
- **Re-analysis no longer loses or hides identity decisions.** An interrupted run's interim cast write cannot swap a persisted id, and a damaged `cast-id-history.json` can no longer be silently rewritten into an empty one, which would have lost every "not the same character" decision; the run log now says so (#2086, #2200, #2201, #2214, PR #2202, PR #2233). A name that gains or loses one trailing surname token between runs ("Anton" / "Anton Petrov") now matches the existing cast row and keeps its voice (#2536).
- **Per-character voice records are keyed by the canonical cast id.** Revisions voice-drift detection, the mixed-engine caption, the Voices "Designed vs Generated" split and speaker QA now count drifted-spelling characters, and a Fix-audio re-record clears a stale "Fallback (Kokoro)" pill. Chapters rendered earlier are not repaired in place; re-render (or re-record the lines) to fix them (#3362, PR #3375).

#### One cast matcher for re-analysis (plan 291)

- **Re-analysis has one authoritative fresh-to-prior cast matcher, and it only ever adds to the cast.** An ambiguous, declined or merged-away match always yields a new row plus a merge suggestion, never a guess. The cast is re-read under lock at each write, so a merge, delete or dismissal made mid-run is not reverted. Dismissals are durable, and **Start fresh keeps your cast, merges, declines and dismissals**, discarding only the analysis cache and per-sentence edits (#4031, #4032, #3954, PR #4103).
- **While a re-analysis runs, the cast is read-only and merges wait.** The cast save is refused with 409 `book_busy`, a "Re-analysis running - cast edits are paused" banner appears, and merge, accept, link and reject controls, "Add character" and add-from-roster are disabled with a tooltip. Voice design, dismiss-suggestion and aliases stay live. A save kept after a connection failure is sent when the run starts (#4031, #4098).
- **A cast.json damaged mid-run is refused, never overwritten.** The run ends with a curated `cast-unreadable` error and the file is left untouched; an authoritative persist failure now ends the run with an error instead of a result (#4031).
- **Background buckets no longer follow a user merge.** A merge of `unknown-male` / `unknown-female` moves that book's lines once and retires the bucket id; later re-analyses put background lines on a fresh bucket (#4031).
- **Known consequences and rollback.** A character marked "Don't reuse" before #3992 whose series link was dropped is no longer re-linked automatically (relink by hand). After a stopped analysis followed by a partial re-analysis, a 0-line leftover character can show until the next full analysis. The analysis cache is now `version: 2`; a pre-v2 cache is a miss in the main job (it starts over) and ends a subset run with `analysis_cache_legacy`. **A revert is not data-safe on its own: revert, then Start fresh (old code), or delete the analysis cache, on books analysed under v2.** On-box acceptance is owed (register Group B).

### 🧠 GPU memory and the sidecar now look after themselves

Two chains land together: refusals are no longer issued against a pessimistic GPU-memory reading, and the TTS sidecar can no longer be frozen by a model unload.

- **A finished render no longer leaves several GB of GPU memory stranded** (#1976). The allocator's reserved-but-unused pool (measured at 3968 MB on an 8 GB card) made later work fail with "not enough GPU memory" until a restart. Admission now reclaims it once, on the failure path, before refusing; `/health` also gains a per-card `vram_reserved_mb_by_device`.
- **VRAM eviction stops as soon as a request fits and never evicts a model that is reserved for work in flight** (#1920, PR #1930). Idle Coqui XTTS is reclaimed under pressure instead of failing the starved operation (#1894, PR #1924; `COQUI_IDLE_TTL`, default 30 s).
- **Pressing Stop no longer reports a timeout while the model unloads anyway** (#1921, PR #1930): unload gets a 90 s budget and the UI shows "Stopping...". A Stop mid-load no longer leaves Coqui pinned to a stale GPU (#1918), and the engine in-flight counters can no longer drift and silently disable idle eviction (#1917).
- **The VRAM readings behind the recycle watchdog no longer mix two cards' figures on a multi-GPU box** (#1997).
- **A voice design is no longer killed by an ordinary synth landing mid-design** (#2070, #2751): the design wins, with a bounded wait, and a wedged one returns a retry-safe 503 (`design_in_flight`). A Base 0.6B render denied capacity by a design on the same card now waits for it (~200 s) instead of failing (#2678, PR #2797).
- **Transcription (ASR) no longer books a cold-load VRAM peak for an already-resident model** (#2094, #3036), and a large `ASR_MODEL` (e.g. `large-v3`) now reserves a realistic 2560 MB instead of 400 MB (#3347, PR #3357); the 2560 MB figure is not yet measured on hardware (register row A110).
- **A voice design or Quality (1.7B) op on an 8 GB card now frees the resident standard Qwen base and a GPU-resident Kokoro instead of failing `noCapacity`** (#4066, #4075; register row A122). A notice says what was unloaded, and the capacity error no longer blames "Preload Kokoro" when it is off.
- **A Coqui-eligible non-English book can now render from "Generate this chapter"** (#1005, #3059); a failed evict no longer kills a mixed Qwen+Coqui chapter (#1893). A mid-chapter Coqui voice repair now prefers the free second card (#3058, #3097, #3207; register row A106).
- **The sidecar's `/health` and other requests no longer stall while it frees GPU memory** (#1919, plan 273): evictions run on a worker thread, and the cold Qwen loads that could hold the Stop button off are hoisted out of the lock (#1975, #2021, #2022). A Stop landing just before a call starts fails that call; the automatic retry almost always absorbs it.
- **Kokoro now actually runs on the GPU on an NVIDIA install instead of silently using the CPU** (#2821, register row A28). The two missing packages are picked up by the one-time reinstall in the upgrade note; the cuDNN version is now pinned to the one torch bundles.
- **Repeated "code 43" device-pin crash-loops now auto-revert to a card with room (or CPU) and show a toast** (#2974, PR #3113; register rows A2/A3). Launchers now pass the real exit code to Node's supervisor; the standalone `npm run tts:sidecar` launcher gets the same restart safeguards and retries CUDA-poison exits (code 42) with backoff (#3121, #3206).

## 🎙️ Voice design, library & previews

- **"Don't reuse" gives a declined series character a voice of its own, with the whole chain of later books linked to it moved along** (#3992, PR #4007; on-box acceptance owed, register row A120). Earlier books' voices and emotion variants are never overwritten by a redesign of the later row. A row declined before this release is separated at its next design or by repeating the decline. The decline is refused with a retry message while a book that may be in the chain cannot be read (#4094), a hand relink back to the declined book puts the row back on that book's voice (#4095), and rows separated before the stored-name fix keep an old name until redesigned (#4067).
- **Series voices share safely.** A first design is shared across the series once, and "Design and compare" shares nothing until kept (#4028, #4072). A design in a book whose cast is not yet confirmed stays on that row and does not restamp earlier books (#4096). Emotion variants are copied with a series mint, never deleted while a row names them, and orphaned files are removed at startup (#4026, #4037, #4062, #4052, #4070).
- **A redesigned base voice marks the emotion variants made against the old base as stale** in every book sharing it, without writing those books; stale variants render in the base voice and are cleaned up at startup (#4040).
- **A consented voice clone anywhere in a series blocks a base-voice or variant write across the whole series** (#2006, PR #2718); a "Don't reuse" row is no longer refused for a clone on the voice it left (#4074). Rebaselining no longer stamps a voice across a decline, the rebaseline modal no longer groups a book with the one that declined it, and the character drawer's series Save now says when the write is refused (#4104, PR #4109; #4110, #4111).
- **The automatic voice match no longer overwrites a locked or tuned voice**, on Confirm, on a manual link and at re-analysis merge (#3842, #3905, #3918, #3920, PR #3934; register row B108). Rows already stamped by the analysis-time linker are left as they are; use My voices assign to replace one.
- **Re-analysis no longer loses a locked voice to an id-drifted duplicate row** (#3965), and a speaker held under two same-name ids no longer takes the series link its twin declined (#4032, partial; remaining shapes tracked in #4031).
- **Voice previews use the character's engine and the book's quality tier** (#1812, #1839, #1841, #1842): a Kokoro-overridden character in a Coqui book now previews in Kokoro, a designed voice's first Play reuses its cached audition, and the Start-generation tier picker disables 1.7B when its weights are absent. A capacity failure now names the model holding the memory and the control that frees it.
- **Voice design and audition endpoints keep the sidecar's 503 "no GPU capacity" instead of flattening it to 502** (#1801).
- **Assigning a designed voice warns, never blocks, when its language differs from the book's** (#1953): the audio would be unintelligible, so the profile drawer and the cast voice panel show a warning with the fix (re-design in the book's language).
- **The profile drawer no longer shows "Default" while saving a stale engine** on non-English books, and the fallback-engine wording is now consistent across the gate, button and message (#1534).
- **`#/voices` facet filters can no longer strand the view as a false "No voices yet"** (#1834, #1866, #1869), and **a second foreign-cast load no longer polls forever** (#3991).

## 🔊 Generation quality & engine health

- **Sibling chapters rendering together no longer lose each other's `state.json` stamps** (#3700, #3711). Two chapters finalizing at once could drop a stamp or, on Windows, fail with `ENOENT`; every `state.json` writer now re-reads and writes under one per-book lock, so a request that raced a delete or folder move gets a 404 and writes nothing. A lock timeout shows a short curated message, never a path. Writes made after releasing the lock against an earlier-resolved folder are tracked in #3711.
- **Voice check (render integrity) no longer misflags correctly-cast voices.** A small synthetic-only audition pool no longer reads as `voice-mismatch`/`severe` (#2934, #3016; stale rows invalidated on upgrade). After you reassign a character's voice, the check and the chapter-row "Re-record the flagged lines" repair (opt-in `qa.speaker.enabled` + `qa.speaker.autoRepair`) stop scoring against the old voice's reference: older-voice lines are written `inconclusive`, re-rendered lines are no longer flagged, and a "too few lines" character is re-checked (#1969, #3414, #3517, #3524, #3676). A character with no line yet in the current voice gets a "no current-voice reference" marker instead of a Resume-scoring button that can never clear.
- **A sidecar that exits while still holding its port is now replaced automatically** (#2037). Previously TTS read as ready with no sidecar listening until a manual restart; refusals now retry on the normal backoff and a spent budget surfaces visibly (`POST /api/sidecar/restart` still recovers).
- **Coqui / Russian, French, Spanish dialogue.** A line opening with a dash now gets a real pause, and doubled commas around dashes are folded (#2026, #2059). Coqui gains `tts.coqui.degenGuard`: an implausibly short render retries once, and a still-degenerate one fails instead of shipping short audio. An ASR content-QA gate can now flag a fluent wrong-language collapse (`qa.asr.catastrophicWer`, default 0.85) (#2055). Known gaps: the Russian `-ее` mispronunciation is baked into the XTTS checkpoint and not locally fixable; audible effect awaits on-box acceptance.
- **Coqui/XTTS no longer 500s after an ECAPA speaker embed** (#1944, #1962, #1963). Several speechbrain proxy modules are evicted; a new "Pin Coqui import order at startup" Advanced Settings knob (default on, only when XTTS weights exist, about 12 s startup) is belt-and-braces. The failure message no longer blames missing PyTorch.
- **Engine health tells missing from broken packages.** Kokoro, Qwen and Whisper now report a real import result (#1965, #1986); Setup, diagnostics and Model Manager share one missing-vs-broken verdict and offer the matching Install or Repair (#1999, #2533). This also turns a false "a voice engine is ready" into a correct blocker when a package is confirmed absent.
- **Content-QA hardening.** An ASR hiccup (bad `qa.asr.model`, wedged transcribe) no longer aborts a finished chapter render (#2011). Non-English WER caps are calibrated to 0.45 for es/fr/de/ru and the global `qa.asr.maxWer` reaches them again (#1084, #2952). Devices chosen in Advanced Configuration (Whisper `qa.asr.device`, Voice-QA `qa.speaker.device`) now reach GPU capacity retry, an incompatible device/compute-type pair is refused at save, and a rejected `.env` device value no longer reaches the sidecar (#2178, #2180, #2207, #2224).
- **GPU placement.** Kokoro now warns on the device panel when it silently runs on CPU despite a GPU setting; a deliberate admission onto CPU does not trip it (#2647, #2643, #2719; on-box A33/A102). Every ROCm/AMD engine load with capacity admission on would have failed; fixed (#2813; no ROCm hardware to verify, logged as owed).
- **Loud-fallback chapters.** "Render anyway" now actually reaches the server and re-dispatches (#3029, #3144); a parked chapter shows a persistent "N chapters need your input" banner after 60 s (#3105, #3106); a generation connection that dies mid-stream now marks the chapter Failed with Retry instead of holding a worker slot forever (#3026).
- **Every stored cover is now a re-encoded JPEG**, so a crafted or GIF/WebP cover can no longer break m4b export (#3535). Portable-bundle import re-encodes its cover the same way and answers failures with a fixed path-free message.

## 🎧 Listening & revising

- **Removed the "Preview as listener" button and page**, which crashed the app with a hooks error (#4014).
- **Re-recording one character's lines can no longer render another character's lines in their voice** (#1972). A re-record now refuses, naming how many segments changed owner, when analysis has run since the last render; re-run analysis or regenerate the chapter. Full chapter generation was never affected.
- **Audio-QA repair has a Listen-view button** ("Scan & repair" on the chapter row, shown only for `suspect` chapters) (plan 179). A repair or splice finishing after a book switch no longer stamps the wrong book's chapter; the splice `warning` frame is now toasted; tablet touch targets restored to 44 px (#1935).
- **Listen timeline shows the chapter-title segment**, and a latent off-by-one that made "Fix this line" target the previous line is fixed (#412). A repaired line's "substituted voice" flag no longer goes stale (#1888, #2034).
- **A correctly-normalised chapter no longer shows a false "off target" loudness pill** (#1922, #1923). QA and the Listen badge now share one real measurement; `scripts/relufs-existing.mjs` upgrades older chapters. The true-peak clip check still cannot fire under shipped defaults (threshold decision left to #1909).
- **A new Fix-audio or regen take no longer vanishes within ~30 s** (#3376, #3395, #3397). Pending A/B revisions survive polls, reloads and book switches, and a take finishing while you are on another book shows on return. Failed saves on leaving a book are re-sent, and a re-send can never undo a newer change: the server rejects a stale one with 409 `stale_revision` (#3421, #3755, #3784, #3827, plan 289). Stalled reads time out with a retry notice (#3426); a persisted edit made while the slices hold another book is dropped (#3624, #3754); deleting a book clears its open slices (#3841).
- **`revisions.json` is now server-owned** (plan 286, #3400). The client never writes it (an old tab gets `400 revisions_server_owned`), accept/reject use per-op routes, and the legacy `…/audio/previous` routes answer 410. Legacy stuck entries show as "Recovered from before the update". Bulk poll errors are per-book and path-free. Owed: on-box A114.
- **Chapter restructure keeps audio and reviews together.** A renamed or renumbered chapter keeps its pending A/B review (#3911, #3704); reorder no longer hands an excluded chapter's audio to its neighbour (#3919); merge, split and reorder move m4a/ogg audio, `.previous` takes and sidecars with the chapter and carry `held`/engine/QA fields; excluded chapters stay out of totals, banners and Regenerate; edits are disabled with a visible reason while a restructure runs.
- **Boot fsck no longer reverts an m4a/ogg chapter to its previous take** on every server start (#3457).
- **Revision diff "Listen back-to-back" works on real revisions**, waits for each take to end and skips a take with no audio (#4002).
- **Series-memory share card and reveal no longer use a failing-contrast accent** on their dark surface; the exported PNG is now AA-compliant (#1832).

## 🗣️ Analyzer, script review & manuscript

- **OpenAI-compatible analyzer endpoints are selectable** (#3084, #3710). Model Manager → Analyzer endpoints adds, edits and deletes named servers (llama.cpp / llama-swap, LM Studio, vLLM, LiteLLM, OpenRouter) with a required served context size, an origin-bound API key (re-enter it if the host changes), a GPU card setting, an optional unload URL, concurrency, request ceiling and structured-output mode. Endpoint models appear in the pickers; refusals show next to their field. A wiki page, `OpenAI-Compatible-Analyzer-Endpoints`, covers setup per server, fallback, chunk size, overflow and troubleshooting.
  - **New fallback setting, `analyzer.fallback.target`** (`ANALYZER_FALLBACK_TARGET`; `off` / `local` / `gemini` / an endpoint model; default `gemini`). It replaces the old `allowCloudFallback` rule for Ollama and endpoint primaries: one hop, only when the primary is unreachable. **Anyone who adds an endpoint and has a Gemini key falls back to Gemini by default**; switch it off or retarget it in Advanced Settings → Analyzer fallback. A saved `allowCloudFallback: false` reads as `off`, and the Model Manager Cloud fallback row is gone.
  - **After a fallback the switch is sticky for the run.** Later calls go straight to the target, the target's GPU is held only once it activates, and an oversized request for a smaller-context target is split or fails clearly (`AnalyzerTargetInputTooLargeError`) rather than being silently truncated.
  - **TTS can unload an idle endpoint** to free its card (one unload POST per model, never while the endpoint is busy); the failure message names what still holds the card.
- **Persona generation can use any analyzer engine, including an endpoint model.** `analyzer.personaGeneration.engine` (`PERSONA_GEN_ENGINE`) accepts `local`, `gemini` or `openai:<endpointId>::<model>`; existing values keep working. When the persona engine shares the voice card and a render is streaming, design entry points ask "Pause audio generation to design voices?" before starting. A shared-card persona engine that is unreachable or times out ends the design job once, with a specific failure code, instead of failing every character. Pausing Design full cast now cancels an in-flight persona request. (#3777, #3084)
- **Restructure fixes for books from v1.14.0 and earlier.**
  - **A restructure no longer rewrites a heading that really says "Chapter 1"** (#3628, #3689). Only titles the app itself made up are renumbered after a merge, reorder or exclude; a title you type is never renumbered.
  - **A merge, split or reorder now survives a restart and travels with the book bundle** (#3703). Books restructured before this version are not repaired; a reparse followed by a fresh restructure brings such a book under the new file.
  - **A renamed copy from a portable-bundle import no longer shares its source's `manuscriptId`** (#3823). Twin books no longer share restructure hints, analyzer cache or re-parse state. A same-device renamed copy now opens like a cross-device import (chapters unattributed); twins already on disk are not repaired.
- **Dialogue detection for non-English and badly-converted books.**
  - **The dialogue-structure aligner no longer strands a whole chapter on one ambiguous short line** (#2187). On the reference Russian book, alignment rose from 67.7% to 96.0% and every chapter now clears the correction floor.
  - **Dialogue lines in EPUBs that lost their paragraph breaks keep their speaker** and are surfaced as low-confidence instead of being silently rewritten to `narrator` (879 lines on the reference book). `structureReport` splits `flagged` into `flagged` and `unresolved` (#2253, #2266).
  - **An unsupported book language no longer demotes the whole book to narrator**, and `isSpokenLine` now reads the per-language quote tables, fixing missed German quote forms and CJK quote-only lines (#2245). A leading dash is not treated as dialogue in en/de/zh/ja (declared narrowing, #2279).
  - **Quote conventions real manuscripts use are now recognised in all seven languages** through a lower-priority `secondaryQuotePairs` tier that can never delete a turn, including drifted German forms (#2279, #2286, #2288, #2315). Known gaps: a book typed entirely in a secondary convention can lose its speaker (#2346), and a second Swiss `«…»` turn in one German paragraph is not recognised (#2352).
  - **A paragraph that re-opens a quote glyph it never closed no longer swallows the next turn** (#2315). Dialogue in single quotes is no longer cut at the first apostrophe (`‘I don’t know,’` read as `I don`) (#2288, #2300).
  - **Spanish and French dialogue dashes written as `&ndash;` now open dialogue** (#2289). `stripHtml` now decodes the full HTML5 named-entity set, so entities like `&eacute;` or `&hellip;` in titles and text are no longer read aloud literally (#2310).
  - **`POST /api/books` rejects an unsupported language** with 400 `unsupported_language` instead of failing opaquely at render time (#1955).
- **Analyzer rosters keep the manuscript's script.** A non-English roster's `name` / `aliases` now follow the prose exactly as spelled; a Russian book had come back 59% transliterated, which then propagated book-wide (#2313).
- **Attribution collapse is now measurable.** A read-only `scripts/measure-attribution.mjs` reports the share of dialogue attributed to the narrator, counted from the source prose so a model stripping a dash cannot fake a recovery; no threshold or UI ships yet (#1984). Plan 247's legibility check now also measures paragraph structure directly (`maxMergedTurnsInParagraph`, bar `< 10`) instead of inferring it from confidence (#2267).
- **Analyzer pill and emotions.** The analysing-view Load/Stop pill no longer briefly shows a stale residency during an unload or load (#1929). Detect emotions can be scoped to the current chapter, with whole-book in its ⌄ menu (fs-35, #592).
- **A book that hands every spoken line to the narrator is now caught instead of shipped** (#2325). For dash-marked languages (Russian, Spanish, French) the stage-2 coverage guard now checks how much speech went to the narrator (a collapsed Russian run had shipped 95.7% narrator with nothing flagged) and retries the section; a still-collapsed chapter reports a new `attribution-collapse` failure, and a Retry of it re-reports the failure instead of clearing it (#2342).
- **An identical attribution failure now re-splits the span instead of burning the retry budget** (#2304). Two identical failures in a row stop the retries and re-attribute the span as two smaller ones, on both the single-call and chunked paths.
- **The coverage guard's retry no longer keeps the worse of two takes** (#2342). A severity-tiered comparison picks the better take, and a model that drops its own dialogue dashes no longer passes the guard silently.
- **Analysing phase cards show a paused or halted run** (#3172, PR #3198), and another book's or tab's paused snapshot no longer paints this book's cards.
- **Settings and analysis fixes found on real books** (#2365, #2427). A `user-settings.json` saved with a UTF-8 BOM (Windows Notepad, PowerShell 5.1) used to make every setting silently revert to its default; BOMs are now stripped. The "Estimated stage time" log no longer claims a measured basis. A Russian "Как сказал маг," is no longer read as a character name, and a German turn introduced by a leading tag (`sagte er: «...»`) is no longer deleted.
- **Ollama multi-GPU split detection** (#2367, #2753). A best-effort `nvidia-smi` probe warns when a resident Ollama analyzer model is split across GPUs though it would fit on one, shown in Advanced Settings (`GET /api/ollama/gpu-split`). Optional `analyzer.ollama.expectedDevice` sharpens it; `gpu.split.probe` turns it off. Informational only.
- **Analyzer settings that did nothing, or lied, are fixed** (#3141, #3200, #3139). The Ollama URL and per-phase analyzer models are read-only in the Model Manager (edit in Advanced Settings). The analysing view's phase-model swap is now a per-run pick, not a settings write. The inert "Analyzer engine" control is gone, and hints pointing at the Account page now name Admin -> Model Manager or Admin -> LAN access. Saved Gemini rate-limit overrides (RPM/TPM/RPD) now take effect live.
- **Analysing view and job hang fixes** (#3173, #3202). An idle analysing view no longer looks running before Start. An analysis job that failed during setup, and a single-character voice design that failed reading `cast.json`, now end with an error instead of hanging (the design hang blocked all later analysis and design for that book until a server restart). Other detached background writes now fail loudly, and lock-timeout messages no longer leak workspace paths. Re-analysing a different chapter during a subset retry now shows "subset in progress". Analysis start/subscribe outcomes are logged.
- **Analysis cache and `manuscript-edits.json` writes land in call order** (#3427, #3430), so an older snapshot can no longer overwrite a newer one on Windows.
- **Analyzer parsing** (#3349, #3373, #3084). Responses opening with a `<think>` block now parse instead of burning the retry. Advanced Settings explains how each chunk-size knob derives its budget.
- **Gemini output cap, thinking window and reasoning overflow** (#3373, #3412, #3084). `analyzer.gemini.maxOutputTokens` defaults to Auto (the model's listed limit). Thinking Gemini models get a 120 s thinking window (`analyzer.gemini.thinkingIdleTimeoutMs`) instead of the 45 s watchdog; every request has a 30 min ceiling. A reply with no answer text and reasoning evidence fails as `analyzer-reasoning-overflow` and stops new spend; the failure names the chapter, model and engine and lists "How to fix" deep links to the exact settings rows. An empty Ollama response at the context limit now splits the chunk. **Budget change:** the Gemini per-request input cap is `min(maxInputTokensPerRequest, the model's TPM)`, so a TPM env var or override below 12000 shrinks chunks; the maximum is lifted to 1,000,000.
- **Analysis runs stop cleanly and retries are safer** (#3435, #3503, #3505). Every analysis ending (Pause, error, overflow, quota) aborts in-flight model calls; those chapters are left for the next Resume or Retry. Retry, Re-analyse and Include are refused (409) while a main analysis runs or drains. A Pause between chapters persists nothing; Start fresh un-confirms the cast and checks the book folder first. A per-chapter Retry no longer reports a half-attributed book as finished. Failure rows say whether cast detection or attribution failed, soft stops read "needs action", and chapters with no narratable text show "exclude it" guidance. Editing speakers in a chapter awaiting re-attribution is replaced by the re-attribution.
- **Book switches can no longer write one book's data into another** (#3435, #3505, #3840, #3908). Voice match, cast updates, late analysis results and emotion detection apply only to their own book; Confirm's voice match re-runs after a mid-match cast change. An analysed book whose emotion detection did not finish is quietly re-run (background, fill-only) when next opened.
- **Structured-output mode and clearer analyzer failures** (Refs #3084). New `analyzer.ollama.structuredOutput` (default `schema`) and `analyzer.gemini.structuredOutput` (default `json`). New failure codes `analyzer-request-rejected`, `analyzer-invalid-output`, `analyzer-endpoint-missing`; invalid-key 400s and Ollama 401/403 are now `auth` with per-source copy. Saved API keys are stripped from analyzer errors, and a bad endpoint entry no longer discards other settings (saved to `user-settings.invalid-endpoints.json`).
- **Voice-style persona and Gemini TTS sample requests now time out** (#3724) instead of depending on the SDK.
- **Reasoning controls for every analyzer engine** (#3084, #3834). Per-model reasoning levels for Ollama (default `off`), Gemini (default `model-default`) and endpoints, offered only if that model's Test accepted them; a rejected or stale level refuses the run before the first call. Overflow failures link to the model's reasoning row. Also fixed: a settings deep-link highlight staying lit, and endpoint editor 44 px touch targets.
- **Custom request parameters for every analyzer engine** (#3084 wave 5b, #3878). A JSON object merged into the native request for Ollama, Gemini and endpoints; pipeline-owned keys, Gemini `httpOptions`/`stopSequences`, prototype-pollution keys, vLLM's structured-output fields, `enable_thinking` (unless reasoning is not controllable) and LiteLLM's `drop_params`/`additional_drop_params` are refused (#3904, #3921). A payload output cap disables Auto. Payloads are never logged and long string values are redacted from that request's errors; do not put credentials in them.
- **Parse-fallback chapter hints are checked against saved analysed sentences** (#3837, #3953, refs #3879). A same-count reorder is no longer accepted and a parser-renamed title no longer wrongly refuses restructure of an analysed book. After re-parse, replace-manuscript, bundle overwrite or backup restore, generation halts with "No analysed sentences cached" until the book is re-analysed; restore answers 409 `book_busy` during a long job.

## ⚙️ Setup, prerequisites & dependencies

- **Minimum ffmpeg is now 6.0, checked at setup** (ops-35, #1877). A too-old ffmpeg shows a warning (never a block) and the Setup Wizard gets a matching card; Pinokio installs `ffmpeg>=6`. **Ubuntu 22.04 (ffmpeg 4.4) is no longer a supported baseline**; a snap or PPA ffmpeg satisfies the floor.
- **Node floor raised 20.19 to 22.22; react-router 7 to 8** (fe-56, #1859, #1878, #1876). `engines` is advisory, so older Node fails late rather than at install. Pinokio now installs a pinned Node 24 itself; **an Update from an older release picks the pin up one Update late**. On-box check owed (E1). The `#/...` URL grammar is unchanged.
- **`ASR_MODEL` and `ASR_COMPUTE_TYPE` are now Advanced Configuration settings** (#1988, #1989, #2014). Previously a UI-set Whisper model reached the sidecar but not Model Manager, so **Remove** could delete the wrong model's folder; sizing, install state and Remove now follow the configured model.
- **Sidecar engine dependencies updated** (#1846, #1843, #1844). `kokoro-onnx` 0.5, FastAPI 0.140 and uvicorn 0.51 (moved to a `lifespan` handler, startup order unchanged). `torch` 2.12+ and `transformers` 5.x stay upstream-blocked (#893, #1228).
- **`onnxruntime-gpu` is pinned to `>=1.26,<1.27`** (#2534, #2576). 1.27+ targets CUDA 13, so on the shipped CUDA 12 stack Kokoro silently fell back to CPU. Installs on 1.27/1.28 step back to 1.26 on upgrade.
- **Installing Qwen3 or Whisper can no longer clobber the GPU ONNX runtime** (#2192). A pip-consistency marker keeps `pip check` clean on NVIDIA boxes, and the server self-heals older venvs at boot. Before, pip could crash with `WinError 5` or silently reinstall the CPU build.
- **In-app Qwen3, Coqui XTTS, Kokoro and Whisper installers now stop the sidecar while they run, then restore the GPU ONNX runtime and restart it** (#3039, #3056, #2192, #3038). A stalled installer is killed by an idle watchdog; installing is refused mid-render; an install error is reported as the install's error. With auto-start off, Castwright never kills a sidecar you started yourself.
- **Fresh installs no longer start with every setting locked** (#2179, #2210). `server/.env.example` ships knobs commented out; **existing installs keep their active lines** until you use the new **Clean up** notice in Advanced Configuration (#2194), which comments out leftover defaults after backing up `.env`.
- **Dependency and security refresh** (#1863, #3241, #3242, #3275, #2411, #2424, #2817, #3431, #3528, #3530, #3531, #3719, #3790, #3826). Cleared advisories in `adm-zip` (override `>=0.6.1`; it parses every EPUB upload, GHSA-xcpc-8h2w-3j85, GHSA-7q85-xj36-vmfc), `undici`, `vite` (dev server), `proxy-addr` (critical, IP spoofing), `sharp`, `multer`, `body-parser`, `shell-quote`, `brace-expansion` and others; root and server `npm audit` are clean with no waivers. The server answers 415 to unsupported `Content-Encoding`. React 19.3, vitest 5. **After the Playwright bump, run `npx playwright install chromium` again.** Held back: `eslint`, `typescript` 6.1 (#711, #1477), `jsdom` 30 (#2823); `torch` alerts stay upstream-blocked (#893).
- **Cover upload now checks the file's actual bytes, not its declared type** (#3533). A mislabeled SVG or non-image is rejected (415) before it reaches the image library; undecodable JPEGs return 502.

## 🔌 Sync & server infrastructure

- **Duplicate book IDs are repaired at startup; the twin with the most work keeps the id** (#3713, #4004, #4029). The other twin gets a fresh id (and fresh manuscript id with its own hints and analysis state when they shared one); both folders are named in a dismissible banner. After a repair, the server refuses writes to that book from any page loaded before it and the page reloads itself (at most twice per five minutes). **Reload any tab left open across the upgrade.** Queue changes are serialised so concurrent starts and clears no longer drop each other's writes.
- **One click re-links this computer's browser to `castwright.local`, and authorizations last a year** (srv-90, #2247, #2257). Admin, LAN access, **Authorize this browser** (from `localhost` only); the device-token lifetime default moves 30 to 365 days (max 400). **Existing authorizations keep their old lifetime; re-authorize a device to extend it**, and a saved override is kept. Re-authorizing replaces earlier "This computer" records.
- **LAN authorization hints are clearer and name the real port** (#2278, #2258). A lapsed authorization says so and points at the right address, using the port Castwright actually bound rather than a fixed 8443. The friendly pairing link also survives a down `:443` forwarder.
- **Revoking a LAN device is now loopback-only** (#2269). It previously worked from any authorized device, including revoking the host's own credential; now open `https://localhost:<port>` on the Castwright computer. `castwright.local` no longer works for revoke.
- **Mock-mode config now mirrors the server registry** (#2259, #2270); mock mode no longer preloads Kokoro by default.
- **The TTS sidecar supervisor can no longer probe a foreign process's port forever** (#2106). A slow probe no longer resets the respawn budget, the port probe is time-bounded, and the supervisor reports the sidecar crashed after a bounded number of tries. On-box acceptance A46 is owed.
- **A folder rename or delete can no longer split a book across two folders** (#3711, #3714, #3717, #3774). Per-book operation locks serialise changes; rename, delete, re-parse, replace-manuscript and chapter restructure/exclude are refused with 409 `book_busy` while a render, analysis, scoring, export or similar job is running. In the Generate view, Include is disabled while a job runs. Also fixed: setting a cast tier on a standalone book changed nothing, and a bulk Include could delete a chapter with no analysed sentences.
- **`state.json` and `user-settings.json` recovery and write ordering hardened** (#3694, #4088, #3400). A crash mid-save no longer loses a book's state (the previous backup is served and written back), a library scan no longer briefly serves the stale backup during a save, an unreadable settings file no longer silently resets to defaults (the Account view shows a banner and refuses saves). Deleting an unreadable or never-analysed book now actually removes its folder. Re-parse and replace-manuscript refuse a `revisions.json` from a newer server before touching anything.
- **A stale client can no longer revert a finished render** (#3683, #3776). `PUT /books/:bookId/state` keeps each chapter's render date, duration, engine, QA and failure stamps from disk.
- **Malformed JSON, oversize bodies and bad encodings now answer 400/413/415 instead of `500 Internal server error`** (#3793).
- **Book-state reads across the app are bounded at 15 s and retried** (#3967): Confirm, the Analysing view, the prosody auto-trigger, duplicate review, the rebaseline modal and the Voices foreign-cast read no longer hang on a stalled server.
- **Screens for one book never render another book's cast, and "Why we matched" shows real data** (#4081, #4082). Confirm and the Ready views wait until the loaded book is the route's book, or show a not-found state; the match-detail panel shows the row's real match factors instead of demo fixtures.

## 🏗️ Under the hood

- **Two checkouts can run their own TTS sidecars at once** (#2632, #2635, #2887, #2888, #2641). The server honours the per-checkout sidecar port for spawn, adoption and every health/GPU probe, instead of hardcoding `:9000` and adopting a sidecar it did not own.
- **Kokoro never reached the GPU, and now can** (#2631, #2600, #2617). Provider selection always fell back to CPU, and `onnxruntime-gpu`'s swap never installed its cuDNN 12 dependency, so Kokoro ran silently on CPU. The sidecar now builds the session itself, installs cuDNN and logs whether it is findable (`KOKORO_DEVICE=cpu` still forces CPU); cuDNN is picked up by the one-time reinstall in the upgrade note. Whisper and the speaker engine also restore their device pin after a CPU fallback (#2642, #2743, #2750, #2784).
- **Kokoro cold loads and VoiceDesign no longer collide on 8 GB cards** (#2752, #2790, #2809, #2810, #3086, #3142). Cold Kokoro loads and the VoiceDesign forward now go through one VRAM arbiter, and a design arriving mid-load evicts correctly. A Quality (1.7B) render also no longer has its own 1.7B-Base evicted or unloaded mid-render (#4079).
- **Paired-device tokens are harder to break or abuse.** A token with a malformed `expiresAt` authenticated forever (#2144); records are validated on load, a bad record is quarantined rather than erased, a transient read failure no longer wipes every pairing, and an operator can delete a quarantined record without a restart (#2149, #2182, #2183, #2208). `/workspace` now serves an allowlist, so one paired device can no longer read every other device's token record, or the update backup snapshots (`.upgrade-backups`, which can hold a plaintext copy of a saved Gemini API key) (#2223).
- **A book's language is decided from its body, not its front matter** (#2251, #2256, #2246). A long foreword or table of contents no longer flips a German, French or Spanish book to English. A book with no stated language no longer silently answers "English" (affected routes now say it is unset), the confirm step keeps the language it detected, and generation no longer leaks worker slots on that failure (#2395, #2515, #2335).
- **Dialogue lines in dash-marked languages (Russian etc.) align to the right place in the manuscript** (#2537, #2540, #2577, #2608, #2799); short replies like "да." no longer match inside other words.
- **Concurrent edits no longer silently overwrite each other in `cast.json`** (#2000, #1981, #2001, #2099, #2155, #2185). Writes are serialised per book, and a stale analysis merge base is now reported instead of silent. A reparse that finds no readable `cast.json` keeps the existing cast carryover (#4039).
- **Bulk "Design full cast" no longer halts on the first Gemini persona failure**, and the toast names the real reason, e.g. a missing API key (#3027, #3161). Emotion-variant design falls back to the base persona (#4085-#4087). `cast_incomplete` / `stage1_shrink_refused` halts show as a neutral "Needs action" state, not a failure (#3203).
- **Chapter restructure and analysis can no longer undo each other** (#3400): each is refused while the other runs on the book. A restructure prunes only chapters with no text (#3783); merge/split/reorder and analysis refuse when the manuscript no longer pairs with its saved state (#3791, #3829); title refresh follows parse origin (#3828). Attribution ids that drifted in spelling no longer undercount a character's lines (#3440, #3451).
- **Book safety.** Renaming a book during analysis is refused (409), and an analysis whose folder was moved outside the app halts loudly instead of resurrecting it (#2361, #2196, #2229). A malformed `user-settings.json` is recovered from backup and flagged by a banner (#3175, #3195). Voice-library revoke/delete no longer return absolute paths (#3720).
- **Install and operator polish.** A flashing console window during install/upgrade is gone (~40 spawn sites, #2567, #2566); `npm run start:prod` no longer refuses to start because a sibling checkout holds the port (#3030, #3262); Advanced Configuration shows rejected saves instead of silently reverting (#2209, #2221, #2344); a slow Ollama prefill is no longer misread as an unreachable daemon (#2287); a failed export no longer crashes the server (#2301); on server death the sidecar logs its exit code and waits before exiting (#4054, root cause still open); 13 CodeQL alerts cleared (#2416, #3721).
- **Contracts and guards.** `/api/setup/*`, the design SSE endpoints and `analysis/state` are in `openapi.yaml` (#1883, #1934, #3787); knob-to-wiki sync, the import-cycle baseline and on-box register citations are mechanically checked (#2012, #2053, #2013, #2721, #2846, #2878).
